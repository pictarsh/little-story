## Description
The Little Store project features a sleek product profile page that vertically layers a customized promo-badged image over background accents, paired below with neatly styled product details and price tags where item titles and favorite buttons are pushed to opposite edges for a balanced, perfectly aligned layout.

## Swift API Reference
### Layout
- **VStack()** : Stacks elements vertically (top to bottom).
- **HStack()** : Stacks elements horizontally (left to right).
- **ZStack()** : Stacks elements on top of each other (back to front, like layers).

### Content
- **Text()** : Displays text on the screen.
- **Image()** : Displays an image.
- **Spacer()** : Flexible empty space that expands to push adjacent elements apart.

### Modifier
- **.font()** : Sets the style, size, or weight of the text.
- **.padding()** : Adds space inside around the edges of an element.
- **.resizable()** : Allows an image to be resized to fit its container.
- **.frame()** : Sets specific width, height, or alignment bounds for an element.
- **.alignmentGuide()** : Customizes alignment reference points to precisely align elements.
- **.background()** : Places a color, image, or view behind the current element.
